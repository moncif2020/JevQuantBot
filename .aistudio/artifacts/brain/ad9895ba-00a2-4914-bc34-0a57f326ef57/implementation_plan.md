# ترقية سجل الشموع التاريخية (3 إلى 5 سنوات) مع التحميل الخلفي المتسلسل والتأمين ضد حظر IP

بناءً على التقسيم الزمني المعتمد وأجوبتك في مرحلة التخطيط:
1. **التقسيم الزمني الديناميكي (Dynamic Tiered Range):**
   - **فريم 1D و 1W:** تغطية 3 إلى 5 سنوات كاملة (~1,095 إلى ~1,825 شمعة يومية / ~260 شمعة أسبوعية).
   - **فريم 4h و 1h:** تغطية 1.5 إلى 3 سنوات (~3,300 إلى ~6,500 شمعة لفريم 4h، و ~13,000 إلى ~26,000 شمعة لفريم 1h).
   - **فريم 30m:** تغطية 6 أشهر إلى سنة (~8,640 إلى ~17,280 شمعة).
   - **فريم 15m و 5m:** تغطية شهرين كاملين (~5,760 شمعة لفريم 15m، و ~17,280 شمعة لفريم 5m).
2. **آلية التحميل المعتمدة:** عرض لحظي فوري لأحدث 1,000 شمعة في أقل من 150ms، متبوعاً باستكمال تلقائي صامت لباقي السنوات في الخلفية (Background Backfill) دون أي وميض أو تجميد للشاشة.

## مراجعة المستخدم والقرارات الحاسمة (User Review & Confirmed Decisions)

> [!IMPORTANT]
> تم تأكيد الخيارات الرئيسية لحماية سرعة الشارت وحدود أمان Binance IP:

- **القرار المؤكد 1 (آلية التحميل):** تحميل فوري لأول 1,000 شمعة (Instant View) لفتح الشارت خلال أجزاء من الثانية، ثم استدعاء الدفعات الأقدم تدريجياً في الخلفية (Background Chunking).
- **القرار المؤكد 2 (عمق البيانات لكل فريم):** تطبيق مصفوفة الفترات المخصصة بدقة (3-5 سنوات للكبير، 1.5-3 سنوات للمتوسط، شهران للفريمات السريعة 5m/15m).
- **إجراءات أمان Binance IP:**
  - رفع حد طلب الشموع الفردي من 120 إلى 1,000 شمعة (أقصى حد تسمح به بينانس في الطلب الواحد بوزن 2 فقط).
  - إضافة دعم `endTime` في خادم Node.js لجلب الدفعات التاريخية السابقة بسلاسة.
  - تخزين الشموع التاريخية المغلقة في ذاكرة الخادم (In-Memory Cache) بمدة صلاحية طويلة، لأن الشموع القديمة لا تتغير إطلاقاً، مما يجعل استدعاءاتها المتكررة تأخذ 0ms وتستهلك صفر طلبات من بينانس.
  - فاصل زمني آمن (150ms Delay) بين طلبات الدفعات الخلفية لتفادي أي ارتداد مفاجئ للطلبات (Bursting).

## 1. نظرة عامة ومفهوم النظام (Overview & Core Concept)

- **ما الذي سيقدمه التعديل:** تحويل الشارت من عرض سطحي مقتصر على 120 شمعة إلى محطة تداول وتحليل فني واختبار تاريخي (Backtesting & Multi-Timeframe Analysis) متكاملة تغطي دورات سعرية كاملة حتى 5 سنوات.
- **القيمة المستهدفة:** تمكين المتداول والبوت من رصد مناطق السيولة العميقة (Deep Liquidity Sweeps)، دعوم ومقاومات القمم والقيعان التاريخية (All-Time Highs & Lows)، ودقة مؤشرات الزخم والتقلب طويل المدى دون أي تنازل عن سرعة الاستجابة.

## 3. القرارات التقنية والمفاضلات (Key Product Decisions & Trade-Offs)

- **القرار الأول: معالجة الدفعات في الخلفية مع دمج المصفوفات (Prepend & Deduplicate):**
  - *النهج المتبع:* تنزيل دفعات بحجم 1,000 شمعة مرتبة زمنياً، دمجها مع الشموع الحالية وإزالة أي تكرار حسب طابع الوقت (`time`).
  - *السبب:* يضمن عدم انتظار المستخدم لعدة ثوانٍ لرؤية الشارت، حيث يرى الشارت خلال 100ms بينما يتم إثراء التاريخ تدريجياً.
- **القرار الثاني: ذاكرة تخزين مؤقت دائمة للشموع التاريخية المغلقة:**
  - *النهج المتبع:* حفظ الشموع القديمة المنتهية في خادم Node.js مع مفتاح `${symbol}_${interval}_${endTime}`.
  - *السبب:* عدم استهلاك حصة الـ IP نهائياً في حال قام المستخدم بالتبديل بين العملات أو إعادة تحديث الصفحة.
- **القرار الثالث: حدود الأمان حسب الفريم:**
  - الفريمات السريعة (5m و 15m) مبرمجة هندسياً لحد شهرين (~17,000 شمعة)، لمنع تجمد محرك رسم الشارت بالمتصفح، بينما الفريمات الكبيرة تصل إلى 5 سنوات كاملة بكل سلاسة.

## 4. البنية المعمارية واستراتيجية تدفق البيانات (Technical Architecture)

```
┌───────────────────────────────────────────────────────────┐
│                    TradingViewChart.tsx                   │
│                                                           │
│  1. Fast Initial Fetch (limit=1000) ──> Instant Render    │
│  2. Background Worker (chunks with delay 150ms)           │
│  3. Merge & Deduplicate Array ──> Update Series in-place  │
└─────────────────────────────┬─────────────────────────────┘
                              │
                    HTTP GET /api/binance/klines
                    (?symbol=BTCUSDT&interval=1d&limit=1000&endTime=...)
                              │
┌─────────────────────────────▼─────────────────────────────┐
│                          server.ts                        │
│                                                           │
│  - Check In-Memory Cache (Hit -> return in <1ms)          │
│  - If Miss -> Fetch from Binance API (weight: 2)          │
│  - Store in Cache (TTL: 24h for historical candles)       │
└─────────────────────────────┬─────────────────────────────┘
                              │
┌─────────────────────────────▼─────────────────────────────┐
│                     Binance Spot API                      │
│                  https://api.binance.com                  │
└───────────────────────────────────────────────────────────┘
```
